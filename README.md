# 🏨 HotelPro NoSQL Database | MongoDB

## 🇺🇸 English Version

### 📖 Introduction
**HotelPro** is a document-oriented NoSQL database designed and implemented in **MongoDB** for the comprehensive management of a fictional hotel chain. The data model efficiently handles daily hospitality operations across multiple interrelated collections:

* `hotel`: General information and branches of the hotel chain.
* `habitación`: Room availability, categories, and features.
* `salon`: Venues and halls designated for events and conferences.
* `cliente`: Guest registration and profile records.
* `empleado`: Operational and administrative staff management.
* `reserva`: Booking control and occupancy status.
* `checkin_checkout`: Guest check-in and check-out logs.
* `consumo_servicio`: Tracking and billing of additional hotel services.
* `evento`: Management of scheduled events within hotel venues.

---

### 🛠️ Tools & Technologies Used
* **MongoDB & MongoDB Compass:** NoSQL database engine used for data storage, modeling, and exporting collections into JSON format.
* **PyCharm (Database Tools):** Integrated Development Environment connected directly to the local database instance (`localhost`) to write and test complex queries and aggregation pipelines (`find`, `aggregate`, `$lookup`, `$unwind`, `$match`).
* **Git & GitHub:** Version control and cloud repository hosting for database backups and query scripts.

# 🏨 Base de Datos NoSQL HotelPro | MongoDB

## 🇪🇸 Versión en Español

### 📖 Introducción
**HotelPro** es una base de datos NoSQL orientada a documentos, diseñada e implementada en **MongoDB** para la gestión integral de una cadena hotelera ficticia. El modelo de datos maneja de forma eficiente las operaciones diarias de hospitalidad a través de múltiples colecciones interrelacionadas:

- `hotel`: Información general y sucursales de la cadena hotelera.
- `habitación`: Disponibilidad, categorías y características de las habitaciones.
- `salon`: Espacios y salones destinados a eventos y conferencias.
- `cliente`: Registro y perfiles de los huéspedes.
- `empleado`: Gestión del personal operativo y administrativo.
- `reserva`: Control de reservas y estado de ocupación.
- `checkin_checkout`: Registros de entrada (check-in) y salida (check-out) de los huéspedes.
- `consumo_servicio`: Seguimiento y facturación de servicios adicionales del hotel.
- `evento`: Gestión de eventos programados dentro de los salones del hotel.

---

### 🛠️ Herramientas y Tecnologías Utilizadas
- **MongoDB y MongoDB Compass:** Motor de base de datos NoSQL utilizado para el almacenamiento, modelado y exportación de colecciones en formato JSON.
- **PyCharm (Database Tools):** Entorno de desarrollo integrado conectado directamente a la instancia local de la base de datos (`localhost`) para escribir y probar consultas complejas y pipelines de agregación (`find`, `aggregate`, `$lookup`, `$unwind`, `$match`).
- **Git y GitHub:** Control de versiones y alojamiento en repositorio en la nube para las copias de seguridad de la base de datos y los scripts de consulta.
