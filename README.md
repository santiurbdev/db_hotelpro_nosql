# 🏨 HotelPro NoSQL Database | MongoDB

### 📖 Introduction
**HotelPro** is a document-oriented NoSQL database designed and implemented in **MongoDB** for the comprehensive management of a fictional hotel chain. The data model efficiently handles daily hospitality operations across multiple interrelated collections:

* `hotel`: General information and branches of the hotel chain.
* `habitación`: Room availability, categories, and features.
* `salon`: Venues and halls designated for events and conferences.
* `cliente`: Guest registration and profile records.
* `empleado`: Operational and administrative staff management.
* `reserva`: Booking control and occupancy status.
* `checkin_checkout`: Guest check-in and check-out logs.
* `consumo_servicio`: Tracking and billing of additional hotel services.
* `evento`: Management of scheduled events within hotel venues.

---

### 🛠️ Tools & Technologies Used
* **MongoDB & MongoDB Compass:** NoSQL database engine used for data storage, modeling, and exporting collections into JSON format.
* **PyCharm (Database Tools):** Integrated Development Environment connected directly to the local database instance (`localhost`) to write and test complex queries and aggregation pipelines (`find`, `aggregate`, `$lookup`, `$unwind`, `$match`).
* **Git & GitHub:** Version control and cloud repository hosting for database backups and query scripts.

---

### 📂 Repository Structure
```text
├── db_hotelpro/                  # JSON backup of all 9 database collections
├── 5 consultas - desempeño.txt   # MongoDB queries and aggregation pipelines
└── README.md                     # Project documentation
```
